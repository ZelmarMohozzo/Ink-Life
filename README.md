# Ink Life Academia de Tatuajes

## Descripción
Sitio web oficial de Ink Life Academia de Tatuajes, dirigida por Nico Lemos. Ofrecemos cursos profesionales de tatuaje, servicios de tatuajes personalizados y remoción láser en Maldonado, Uruguay.

## Características
- **Cursos Profesionales**: Formación completa en el arte del tatuaje
- **Tatuajes Personalizados**: Diseños únicos y profesionales
- **Remoción Láser**: Tecnología avanzada Q-Switched
- **Galería Completa**: Muestra de trabajos realizados
- **Sistema de Reservas**: Carrito de compras integrado

## Tecnologías Utilizadas
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide React (iconos)
- Responsive Design

## Instalación y Desarrollo

```bash
# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev

# Construir para producción
npm run build

# Vista previa de producción
npm run preview
```

## Estructura del Proyecto
